Corresponding source

Everything needed to rebuild and relink this application is public — there is no written-offer step to go through:

  • github.com/Virtastic/freecad-web — build scripts, the front-end shell, and the CI that produces the published binaries
  • patches/ — every modification made to FreeCAD and its dependencies, as applied patches against the pinned upstream sources
  • BUILD-WEH.md — the pinned upstream versions and the exact build procedure, including how to obtain the dependency sources that are not committed here
  • Releases — the published .wasm/.js/.data artifacts, each traceable to the CI run and commit that produced it
LGPL §6 asks that a user be able to modify the covered library and relink the combined work. Because the whole build — sources, patches, flags, and CI definition — is published, anyone can change a component and produce their own binaries with the same procedure we use.

Separate WebAssembly modules (GPL)

ComponentLicenseUpstream
GmshGPL-2.0-or-latergmsh.info
CalculiX (ccx)GPL-2.0-or-latercalculix.de

These are GPL and are deliberately not linked into FreeCAD.wasm. Each is built as its own standalone WebAssembly module (gmsh.wasm, ccx.wasm) with its own filesystem, fetched on demand, and driven through a JavaScript bridge that copies input files in and results back out — the same arrangement desktop FreeCAD uses when it shells out to an installed gmsh or ccx binary. Anyone redistributing this application should confirm that arrangement against their own legal advice rather than relying on this note.
