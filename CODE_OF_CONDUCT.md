# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

Be respectful. Disagree about the code, not the person. Harassment, personal attacks and
discriminatory language are not tolerated anywhere in this project: issues, pull requests,
discussions, commit messages.

Report conduct problems to <michael@stavridis.xyz>. Reports are read by the maintainer,
handled privately, and acted on. The maintainer may remove, edit or reject comments,
commits, issues and pull requests that violate this code, and may ban contributors who
repeat the behaviour.
